## Opening OrgHop

| Shortcut | What it does |
| --- | --- |
| <kbd>Alt</kbd> <kbd>S</kbd> | Open the OrgHop popup from the toolbar |
| <kbd>Cmd</kbd> <kbd>Shift</kbd> <kbd>K</kbd> on macOS, <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>K</kbd> elsewhere | Open the search overlay on top of the Salesforce page |

## In the results

| Shortcut | What it does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Page Up</kbd> <kbd>Page Down</kbd> | Move through the results |
| <kbd>Enter</kbd> | Open the selected result in your org's tab |
| <kbd>Cmd</kbd> or <kbd>Ctrl</kbd> + <kbd>Enter</kbd> | Open it in a new tab (a middle click does the same) |
| <kbd>Shift</kbd> <kbd>Enter</kbd> | Pin or unpin the selected Setup page |

## Changing the shortcuts

Click the shortcut button in OrgHop's footer, or go to `chrome://extensions/shortcuts`, and set the keys you want for "Open OrgHop" and the search overlay.
